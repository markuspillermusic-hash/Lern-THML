# Aufgabenteilung der Skills

- `unterrichts-lernseite-builder`: fachübergreifender Standard für LernHTMLs,
  einschließlich Musik, KI-Feedback, Rollen, Klassenraum und QA.
- `religion-lernpfad`: externes Fachprofil im Repository
  `markuspillermusic-hash/Religions-LernHTML`, mit LehrplanPLUS, theologischer
  und philosophischer Quellenarbeit sowie gA/eA- und Abiturbezug.
- `lernseite-server-portierung`: geschützte Serverinstallation, Migration,
  Backups, Rechte und Live-Abnahme.

Die Skills beschreiben Entscheidungen und Prüfverfahren. Ausführbarer
gemeinsamer Code lebt in diesem Repository. So werden Regeln nicht durch Copy &
Paste auseinanderentwickelt.
