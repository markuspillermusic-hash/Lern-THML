# Learning State Evaluator v1.1.0

Lokale Mehrfachauswertung exportierter Lernstände im Format `version: 2` beziehungsweise `_formatVersion: 2`. Unterstützt werden JSON-Dateien und LernHTML-Sicherungen mit eingebettetem `script#lp-daten`. Dateien verlassen den Browser nicht; Dateinamen werden in der Oberfläche pseudonymisiert. Handschriftliche Data-URLs werden nur gezählt. Die Übersicht misst ausschließlich Bearbeitungsstände und nimmt keine automatische Benotung vor.
