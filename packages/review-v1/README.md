# Review Module v1.2

Raumgekoppelte Wiederholung und mündliche Abfrage:

- Auswahl von Abschnitten und vorbereiteten Aufgaben aus AFB I–III;
- gezielte Einzelanzeige genau einer aktiven Frage auf dem Beamer über den
  persistenten Präsentationszustand;
- Verortung in der Lehreransicht unmittelbar unter der
  Klassenraumvorbereitung und in der Hauptnavigation direkt hinter `Lernweg`;
- vollständige Entkopplung von der linearen Schülerfreigabe und keine
  Auslieferung des Moduls in der Schüleransicht;
- fachlich vorformulierte Fragenbank statt Laufzeit-KI oder schematischem
  Ein-Frage-pro-Abschnitt-Klassenquiz;
- lokale, pseudonymisierte Beobachtungsbausteine, Notizen und eine manuell
  wählbare Notenskala 1–6;
- JSON-/CSV-Sicherung ohne Schülerkonten und ohne automatische Benotung.
